# 0001. 採用 ddddocr 本地開源辨識與 Session 保持機制

## 背景與問題
後台管理系統（`dl02.seiwainc.com.tw`）在登入時要求輸入 4 位數字圖形驗證碼（由 `GetVCode.php` 生成）。目標是建立完全免費且高可用性的自動化查詢 Line 機器人。

## 決策
1. **驗證碼辨識**：採用開源 Python 深度學習庫 `ddddocr`，於伺服器/本地端離線執行辨識。捨棄付費第三方打碼平台（降低營運成本）與 Tesseract OCR（降低複雜的影像前處理維護成本）。
2. **會話管理**：採用「持久化 Session 保持（Keep-Alive）+ 惰性自動重登」策略。查詢時優先重複使用既有的 `PHPSESSID`；僅當後台回應 302（Session 過期）或錯誤時，才觸發自動登入與驗證碼重試迴圈。

## 影響與後果
- 查詢回應延遲大幅降低（已登入狀態下直接查詢約 0.3~0.5 秒，避免每次指令產生 2~4 秒的登入延遲）。
- 完全零第三方 API 成本。
- 需在環境中預載 ONNX Runtime 及 ddddocr 依賴（約需 100~200MB 記憶體空間）。
