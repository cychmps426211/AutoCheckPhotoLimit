# 02 — 剩餘張數門檻過濾 (Threshold Filtering: 底片 < N)

**What to build:**
維修師可透過指定自訂門檻（如「底片 < 20」、「底片門檻 20」、「底片 20張」），查詢剩餘張數低於或等於該數值的機台。系統向後台查詢該維修師名下所有機台，在記憶體中過濾出符合張數條件之機台並升冪排序。若所有機台存量皆高於門檻（0 台符合），則回傳「機台底片皆充足」的提示文字。

**Blocked by:** 01 — 基礎全通路貫通 (Issue #2)

**Status:** ready-for-agent

- [x] 支援「底片 < N」、「底片門檻 N」、「底片 N張」等門檻指令格式
- [x] 查詢能精確過濾出剩餘張數小於或等於 N 的機台
- [x] 回傳結果依剩餘張數升冪排列
- [x] 若無任何機台低於門檻，回傳安心提示（例如「目前維修師 91 負責之機台底片皆充足」）
- [x] 包含端對端 Webhook 測試驗證門檻過濾與 0 台符合的兩種情境
