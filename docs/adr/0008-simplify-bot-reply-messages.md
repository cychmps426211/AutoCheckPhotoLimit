# 0008. 精簡機器人自動回覆訊息格式

## 背景與問題
1. **行動裝置閱讀體驗與版面聚焦**：
   現場維修師在手機 Line 聊天室查閱資訊時，螢幕垂直空間有限。訊息抬頭若標註「維修師 91」，在合併跨維修師協同機台（例如包含維修師 19 負責之機台）時易造成語意混淆，且維修師已知悉自身查詢目的，標註個人編號顯得冗贅。
2. **末端提示語重複累贅**：
   存量警報末端原先均附加「💡 請現場維修師優先巡檢置頂機台補充底片。」（或值班模式之「💡 請值班維修師優先巡檢置頂機台補充底片。」），在維修師頻繁查詢的日常巡檢情境中，此固定提示佔據版面且無實質資訊增量。
3. **未知指令引導簡化**：
   原先未知指令提示「您可以直接輸入「底片」查詢預設維修師 (91) 機台，或輸入「說明」查看所有指令格式。」過於冗長，應簡明聚焦引導至「說明」。

## 決策
1. **底片存量警報抬頭去編號化**：
   - `MessageBuilder.build_stock_report` 標題統一簡化為 `⚠️ 【機台底片存量警報】（剩餘張數 <= N 張）`。
   - 存量充足提示統一簡化為 `🎉 目前負責之機台底片皆充足...` 或 `🎉 目前所有機台底片存量充足...`。
2. **維護行程抬頭去編號化**：
   - `MessageBuilder.build_schedule_report` 標題統一簡化為 `📅 【維護行程】{date_str}`。
3. **移除末端巡檢提示行**：
   - 移除 `build_stock_report` 與 `build_duty_stock_report` 末尾之「💡 請...優先巡檢置頂機台補充底片。」提示。
4. **簡化未知指令提示**：
   - `MessageBuilder.build_unknown_message` 提示簡化為「輸入「說明」查看所有指令格式。」。

## 影響與後果
- Line 訊息排版更加緊湊乾淨，核心警報機台與維護行程資訊在手機聊天室首屏即可一覽無遺。
- 消除協同機台與預設維修師機台合併輸出時抬頭標註單一編號的語意衝突。
- 相關單元測試與端對端測試同步更新並全數通過。
