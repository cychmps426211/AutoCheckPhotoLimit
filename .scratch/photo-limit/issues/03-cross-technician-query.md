# 03 — 跨維修師與複合查詢 (Cross-Technician & Combined Query)

**What to build:**
維修師可查詢其他維修師負責的機台，支援「底片 師 88」、「底片維修師 88」以及複合查詢「底片 88 < 20」。系統將請求參數中的 `uno` 切換為目標維修師編號，回傳訊息抬頭明確標示維修師代號。若該維修師名下查無機台，給予清晰友善的提示。

**Blocked by:** 02 — 剩餘張數門檻過濾 (Issue #3)

**Status:** completed

- [x] 支援指定維修師語法（如「底片 師 88」）
- [x] 支援維修師與張數門檻之複合語法（如「底片 88 < 20」）
- [x] 回覆訊息抬頭動態反映當前查詢之維修師編號
- [x] 查無機台或無效維修師編號時回傳適當提示
- [x] 包含跨人查詢與複合查詢的端對端 Webhook 測試
